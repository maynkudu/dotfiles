# reviewed reflection

Read [host support](../../reference/workflow-hosts.md). Use the current conversation and named artifacts only. Identify the observed failure, supporting evidence, recurrence and smallest existing rule/skill or executable check that should change. Reject one-off or already-covered lessons. Present proposed changes and wait for explicit human approval. Do not spawn a fixed review panel, pick unavailable models, create background observers, file external backlog items or auto-promote saved context into policy. Approved edits follow writing-for-agents and the normal source/build/install path.
