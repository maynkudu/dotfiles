# UI verification

For visible web or app changes, read `~/dotfiles/skills/reference/ui-verification.md`.
It owns surface selection, focused interaction checks, evidence-based iteration,
and the single closeout. Use Agent Browser for ordinary websites, Agent Desktop
for native desktop apps, and Argent for devices, React Native, Electron, and
existing Chromium-CDP sessions.

Operate the real product against the accepted brief. For changed or reported breaking web UI,
read `~/dotfiles/skills/reference/bombadil.md` and run bounded, scoped exploration on disposable
or read-only data. Retain traces and reproduce violations. Pair it with responsive, control,
keyboard, motion and console checks. Fix demonstrated defects within scope and verify again.
Builds and source edits do not establish visible behavior or design quality. Exact copies also
follow `fidelity-first`. Report missing evidence as unverified.

Present the result, compact evidence links, material deviations, and blockers in one
closeout. Do not make the user sort research logs or discarded attempts.
