# Research provenance

The archived notes cover [Apple motion evidence](apple-primary.md), [portable mechanisms](portable-motion.md), [design foundations](design-foundations.md), [interface patterns](design-patterns.md), and [visual observations](visual-observations.md).

Retrieval records are retained for [Apple primary sources](apple-primary-sources/manifest.json), [foundation sources](design-foundation-sources/manifest.json), [pattern sources](design-pattern-sources/manifest.json), [portable originals](portable-sources/original-source-fetches.json), and [framework sources](portable-sources/framework-source-fetches.json). The [Reanimated source pin](portable-sources/reanimated-source-pin.json) identifies the inspected revision. The [equation check](portable-sources/equation-check.py) and its [results](portable-sources/equation-check-results.json) record the independent numerical comparison.

Relative references to downloaded pages, transcripts, papers, and Apple demonstration frames resolve only in the original local research directory. Those raw artifacts are not included in this Git archive. The current skill repository contains the maintained research index and portable recipes.
