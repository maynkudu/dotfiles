# Apple design and animation delivery record

The [approved plan](plan.md) expanded the motion study into a platform-independent skill and three independent Modulo components. The skill, recipes, examples, and numerical tools are maintained in [maynkudu/apple-design-and-animation-system](https://github.com/maynkudu/apple-design-and-animation-system). Codex uses the local `apple-design-and-animation` skill symlink to that repository.

The original [system preview](system-preview.html), its [check notes](system-preview-notes.md), and the [independent skill exercise](skill-forward-test/decisions.md) preserve the reviewed design and executed fixture checks. Earlier component screenshots, install checks, and source-hash drafts record the initial integration. They precede the final notification update and published revision pins.

The final [controls and notification review](controls-notification/review.md) covers custom ranges, switches, dropdowns, action menus, and right-click menus. Liquid Cluster begins as one rectangle, then separates into a notification card and Clear action. Clear dismisses it, while Reset and Replay restore it. The [24 browser checks](controls-notification/checks.json), [runtime errors](controls-notification/browser-errors.json), and desktop, 390-pixel, 320-pixel, full-view, and motion-frame captures record that update. [Installation results](controls-notification/install-check/results.json) verify protected source access, installed file hashes, consumer TypeScript, and immediate revocation. The stale-manifest result records the first failure before registry regeneration corrected it.

The [fresh-checkout record](controls-notification/publication-check.json) verified frozen-lockfile dependency installation, all 57 GitHub source files across nine pinned components, typecheck, and production build. The [publication record](controls-notification/published-repositories.json) confirms all five project repositories were pushed and clean. The [production deployment](controls-notification/deployment.json) passed, and [live HTTP checks](controls-notification/production-http-checks.json) returned 200 for all three pages and 401 for anonymous source downloads.

Elastic Slider, Snap Rail, and Liquid Cluster original implementations remain in private `maynkudu/modulo-<slug>` repositories. This archive contains verification scripts, reports, and captures. Downloaded third-party code, dependency bundles, and intermediate duplicate motion tools remain local under the archive's ignore policy.

Native platform adapters, exact Apple constants and optics, and pixel or timing fidelity remain unverified. Recorded trajectories at 120 fps establish sampling output rather than 120 Hz browser presentation. Browser interactions were verified locally; production HTTP checks establish deployed routes and anonymous source denial.
